A personal collection of GTA V Legacy mods, dependencies, trainers, immersion improvements, physics mods, and random/chaotic gameplay mods.

## 📁 Repository Structure

### `Dependencies/`

Required tools and frameworks used by various mods.

- **ScriptHookV + ScriptHookVDotNet** — compiled together for convenience
- **OpenIV** — required for many `.rpf` modifications
- **OpenIV.asi** — enables the `mods` folder workflow

### `Fun/`

Mods designed primarily for chaotic or unusual gameplay.

- **RiotMode** — turns Los Santos into absolute chaos.

### `Immersion/`

Mods that expand or randomize the GTA V world.

- **RDE** — enhanced law enforcement, emergency response, vehicles, and world content
- **Immersify** — additional immersion improvements
- **Rainbomizer** — randomizes various aspects of GTA V
- **Serial Killer Mod** — random pedestrian/serial-killer gameplay
- **Random Madness** — unpredictable random events and helpful/unhelpful surprises

### `PhysicsMods/`

Mods that change GTA V's physics, ragdolls, gore, and combat effects.

- **Euphoria Ragdoll v9.3**
- **Euphoria Ragdoll v9.4**
- **Improved Gore v4.0**
- **DismembermentGore**

> ⚠️ **Euphoria Ragdoll v9.3 and v9.4 are alternative versions.**
>
> **Install ONE version only. Do not install both simultaneously.**

### `Trainer/`

- **Rampage Trainer** — trainer and gameplay utility.

# ⚙️ Installation

## 1. Install Dependencies

Install the required dependencies before installing the mods.

Recommended order:

1. **ScriptHookV**
2. **ScriptHookVDotNet**
3. **OpenIV**
4. **OpenIV.asi**

Some mods may require additional dependencies. Always check the individual mod's documentation before installation.

---

## 2. Use the `mods` Folder

For OpenIV-based modifications, use the `mods` folder whenever the mod supports it.

This keeps modified game files separate from the original GTA V files and makes troubleshooting significantly easier.

**Do not blindly replace original GTA V files.**

# 🧪 Tested Configuration

The following combination has been tested on:

**GTA V Legacy v1.0.3725.0**

### Stable

- RDE (Base)
- Euphoria Ragdoll
- Improved Gore
- Finite Cops
- Random Madness
- Random Ped Selector
- Rampage Trainer

### Known Problematic

**RDE Expanded & Enhanced**

RDE E&E caused instability/problems in the tested setup and is therefore **not included in the recommended configuration**.

**VisualV**

VisualV was removed from the setup due to repeated instability and compatibility issues during testing.

> If you're looking for a stable setup, **use Base RDE instead of RDE Expanded & Enhanced.**

# 🥛 Recommended Chaos Setup

For a heavily modified but relatively stable Legacy installation:

```text
Base RDE
+ Euphoria Ragdoll
+ Improved Gore
+ Finite Cops
+ Random Madness
+ Random Ped Selector
+ Rampage Trainer
```

Add additional mods **one at a time** and test the game after each installation.

If the game begins crashing, remove the most recently added modification first.
